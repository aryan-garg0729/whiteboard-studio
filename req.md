# whiteboard animation software
User should be able to add images(any format, svg), write text, add audio(mp3, wav)
for images:
- animation should look natural like first high level outline creation then zig zag coloring
- no outline direct revealation in zigzag way
- no other animation required as of now

for text:
- left to right animation following the text character and shapes
- no other animation as of now

The hand should never be fully visible to create realistic effect and not detached hand
Also add a no hand mode
finally i want an erasing animation for both images and text

# timelines

- animations should be easily time adjustable

# page animations

- infinite canvas:
    - zoom in zoom out 
    - move to any other part
